### 2. 홈페이지 이미지 우선순위
파츠의 이미지가 다음 순서로 표시됩니다.

1. `한국 이미지`가 있으면 한국 이미지
2. 한국 이미지가 없으면 `일본 이미지`
3. 둘 다 없으면 기본 자리표시 이미지

상세 화면에서는 한국/일본 이미지를 각각 보여주고, 한쪽만 있으면 있는 쪽만 보여줍니다.

### 3. Google Sheets에서 ID 자동 입력
`GoogleAppsScript_Code.gs` 파일을 Google Sheets의 **확장 프로그램 → Apps Script**에 붙여 넣으면 됩니다.

`파츠` 시트의 A열에 ID를 입력하면 다음 항목이 자동으로 채워집니다.

- B: 카테고리
- C: 이름
- D: 한국 이미지 (이미 값이 있으면 유지)
- E: 일본 이미지
- H: 보유 (새 행이면 FALSE)
- I: 한국실장 (새 행이면 FALSE)

일본 파츠 이름/카테고리/이미지는 공식 일본 파츠 페이지에서 ID와 연결하여 가져옵니다. 일본 공식 페이지에서 현재 이미지 파일이 `.../parts/img/Face_0001.webp`와 같은 형태로 제공되는 것도 확인했습니다.

**중요:** Google Apps Script에서 외부 페이지를 읽기 때문에 `onEdit`는 반드시 **설치형 트리거**로 등록해야 합니다. 아래 순서대로 한 번만 설정하세요.

1. Google Sheets에서 **확장 프로그램 → Apps Script**
2. `Code.gs`의 기존 내용을 지우고 `GoogleAppsScript_Code.gs` 내용을 붙여넣기
3. 저장
4. 왼쪽 **트리거(시계 아이콘)** 클릭
5. **트리거 추가**
6. 실행할 함수: `onEdit`
7. 배포에서 실행: **나**
8. 이벤트 소스: **스프레드시트에서**
9. 이벤트 유형: **수정할 때**
10. 저장 후 Google 권한 승인

이후 A열에 예를 들어 `Face_0001`을 입력하면 자동으로 B~E/H~I가 채워집니다.

### 한국 이미지에 대해
한국 이미지 URL은 한국 공식 사이트에서 일본 ID와 동일한 URL 규칙이 확인되지 않아, 자동 스크립트에서는 D열을 기존 값 그대로 유지하도록 했습니다.

따라서 D열에 한국 이미지 URL이 입력되어 있으면 사이트에서 **무조건 한국 이미지를 먼저** 사용하고, D열이 비어 있으면 E열의 일본 이미지를 사용합니다.

한국 이미지 URL 규칙이 확인되거나, 한국 이미지용 ID→URL 목록을 별도로 주시면 D열까지 완전 자동화할 수 있습니다.

## 파츠 시트 열 구조
`ID | 카테고리 | 이름 | 한국 이미지 | 일본 이미지 | 설명 | 태그 | 보유 | 한국실장`

- `보유`: TRUE/FALSE
- `한국실장`: TRUE/FALSE
- 이미지 셀은 직접 URL을 넣는 것을 권장합니다.
- `=IMAGE("이미지주소")`도 사이트에서 주소를 읽을 수 있지만, 관리용으로는 URL 텍스트가 더 편합니다.

- `» 빠른 선택 «`을 켜면 파츠 카드 이미지/이름을 눌러 보유 상태를 바로 전환합니다.
- 모바일 파츠는 3열, footer는 고정 해제, 카테고리 영역을 상단으로 이동했습니다.

### CODE 기능 설정
1. Google Sheets의 Apps Script에 수정된 `GoogleAppsScript_Code.gs`를 넣습니다.
2. Apps Script에서 `setupAipriUserSheets`를 한 번 실행하여 `사용자`, `보유데이터` 시트를 만듭니다.
3. 웹 앱으로 배포: 실행 주체는 본인, 액세스 권한은 사이트 방문자가 코드 기능을 사용할 수 있도록 설정합니다.
4. 배포된 `/exec` URL을 `script.js`의 `CONFIG.apiUrl`에 붙여넣습니다.
5. 사이트를 다시 GitHub Pages에 업로드합니다.

CODE는 친구용 개인 컬렉션 관리에 맞춘 가벼운 코드 방식이며, 공개 GitHub Pages에서 강한 보안 인증 수단으로 사용하는 구조는 아닙니다.

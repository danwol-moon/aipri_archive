# 아이프리 아카이브 v10.07.10

## 1. 새 Google Sheets 연결
사이트 데이터 원본을 구글 스프레드시트를 사용하여 파츠와 악곡을 구분해두었습니다.
시트에서 이미지와 이름, 한국 실장 여부 등을 불러오게 연결했습니다.

- 파츠 시트: `파츠`
- 악곡 시트: `악곡`

또한, A열의 칸이 비어 있으면 다른 열에 데이터가 입력되어도 사이트에는 표시되지 않습니다.

## 2. 홈페이지 이미지 우선순위
파츠의 이미지가 다음 순서로 표시됩니다.

1. `한국 이미지`가 있으면 한국 이미지
2. 한국 이미지가 없으면 `일본 이미지`
3. 둘 다 없으면 기본 자리표시 이미지

상세 화면에서는 한국/일본 이미지를 각각 보여주고, 한쪽만 있으면 있는 쪽만 보여줍니다.

## 3. Google Sheets에서 ID 자동 입력
사이트 제작자의 편의를 위해 `파츠` 시트의 A열에 ID를 입력하면 다음 항목이 자동으로 채워집니다.

- B: 카테고리
- C: 이름
- D: 한국 이미지 (이미 값이 있으면 유지)
- E: 일본 이미지
- H: 보유 (새 행이면 FALSE)
- I: 한국실장 (새 행이면 FALSE)

일본 파츠 이름/카테고리/이미지는 공식 일본 파츠 페이지에서 ID와 연결하여 가져옵니다. 일본 공식 페이지에서 현재 이미지 파일이 `.../parts/img/Face_0001.webp`와 같은 형태로 제공됩니다.

예를 들어 A열에 `Face_0001`을 입력하면 자동으로 나머지 열(B~I)이 채워집니다.

## 4. 편의사항
- 이 사이트의 정보는 사용한 기기에서의 데이터만 저장이 되는 단점이 있습니다.
예를 들어, A기기에서 사용하던 데이터를 B기기에서 가져오지 못하고 새로운 데이터로 시작해야 됩니다.

사이트 제작자는 이를 해결하기 위해 "CODE"를 만들어서 개인 보유 데이터 기능을 추가했습니다.
CODE를 통해 로그인을 하면 다른 기기에서도 데이터를 불러와서 계속 사용할 수 있습니다.

**CODE는 친구용 개인 컬렉션 관리에 맞춘 가벼운 코드 방식이며, 공개 GitHub Pages에서 강한 보안 인증 수단으로 사용하는 구조는 아닙니다.**

- `파츠` 시트에서 "빠른 선택"을 누르고 파츠 이미지나 이름을 누르면 체크 박스를 누르지 않아도 체크(보유 중) 표시가 되는 기능을 추가하였습니다.
이 기능은 사이트 제작자의 아이디어가 아닌 다른 사이트 제작자의 아이디어로 대화를 한 후 추가한 것 임을 미리 말씀드립니다.
